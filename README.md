### 3. Password Hash Extraction & Recovery

## Tools used:

* Kali Linux (WSL)
* Perl
* pdf2john.pl
* John the Ripper
* Johnny (graphical interface)

### Process:

1. Located the instructor-provided protected PDF.
2. Extracted its password hash using pdf2john.pl.
3. Saved the extracted hash in a text file.
4. Loaded the hash into Johnny.
5. Successfully recovered the password.
6. Verified the recovered password by opening the protected PDF.
